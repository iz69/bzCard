# 利用ガイド

起動済みのbzCardで、名刺を登録・検索・修正する人向けのガイドです。
WebUIのURL、API URL、ログインIDとパスワードは、サーバーの管理者に確認してください。
自分でサーバーを用意する場合は、先に [導入ガイド](../administrators/installation.md) を参照してください。

## ログイン

1. WebUIを開きます。
2. ログイン画面のAPI URLを確認し、ログインIDとパスワードを入力します。
3. 「ログイン」を押します。Androidも同じサーバーの認証情報を使います。

APIを同じドメインのルートで公開している場合、API URLには `/` を指定できます。
プロキシなしでローカル確認する場合のAPI URLは `http://localhost:18081` です。
接続先とログイン情報は配置ごとに保存されます。WebUIの公開パスや初期API接続先が
変更された場合は再ログインしてください。従来の `/bzcard/`・`/bzcard-api` 構成の
保存済み情報は、初回アクセス時に自動で引き継ぎます。

アカウントメニューの「パスワード変更」からパスワードを変更できます。
新しいパスワードは12文字以上です。変更後はすべての端末で再ログインが必要です。

## 名刺を登録する

WebUI上部の「名刺を追加」からJPEG/PNGの名刺画像を選択します。
元画像と補正後画像を保存し、切り抜き・回転補正、文字の読み取り、項目抽出を順に行います。
表面を登録した後、名刺の詳細画面の「裏面も追加」から裏面画像を追加できます。

一覧の状態が `ready` になったら、氏名・会社名・住所・電話番号などの読み取り結果を
確認してください。`not_card` は名刺ではなさそうな画像として処理を停止した状態です。

文字を読む精度は画像品質にも依存します。特に低解像度の画像では、
読み落としや誤読が増えることがあります。

## 一覧・検索・編集

左側の人物一覧から選択すると、右側に名刺の詳細と画像を表示します。
最初に50人を表示し、一覧の下端に近づくと追加で取得します。
追加取得に失敗した場合は「続きを再試行」を押してください。

検索は表示済みの人物だけでなく、自分の全登録名刺を対象にします。
複数の検索語を入力すると、すべての語を満たす人物を表示します。
同じ人物の異なる名刺に検索語が分かれていても検索できます。
メールアドレスまたは携帯番号が一致する名刺は同じ人物にまとめます。
氏名や会社名だけの一致ではまとめません。

読み取り結果が違っている場合は詳細画面の項目を修正し、「保存」を押します。
各名刺はログイン中の利用者に紐付き、別の利用者の名刺を参照・編集することはできません。

## 再スキャン・再抽出

画像から読み直す場合は「再スキャン」、保存済みのOCRテキストから項目を抽出し直す場合は
「再抽出」を使います。読み順は「自動判定」「横書き」「縦書き」から選択できます。
手動回転と自動回転は表裏ごとに記録し、再スキャンにも適用します。

`error` の名刺は、エラー内容を確認してから再スキャンできます。
画像変更・削除・再処理が競合した場合は、処理の完了後に再試行してください。

**解析完了時には、保存済みの手動修正が解析結果で上書きされます。**
処理結果を確認してから修正してください。別に保存された補正履歴は残ります。

## 補正履歴

修正を保存すると、実際に変更された項目を補正履歴へ記録します。
名刺の詳細画面の「補正履歴」で確認できます。履歴がない場合は項目を表示しません。

現在、次の読み取りに参照するのは、有効な「かな」の補正です。
参考にできる履歴には「読み取りの参考にする」のチェック欄があり、
無効化・再有効化できます。再訂正した以前の補正は無効化され、履歴として残ります。

印刷されたかな・ローマ字を優先し、同じ利用者が確認した読みを参照します。
他の利用者の補正を使うことはありません。
モデルを自動学習する仕組みではなく、確認済みの訂正を次の解析で参照します。
初めての氏名や、氏名・連絡先を読み取れない画像での精度向上を保証するものではありません。

更新前から保存されていた名刺は当時の解析履歴がないため、初回の訂正を変更履歴として残します。
再スキャン・再抽出後の訂正から、解析結果との対応を記録します。

## LINE連携

利用者ごとに、自分のLINE公式アカウントを設定できます。
Messaging APIのチャネルシークレット・チャネルアクセストークン、
LINE LoginチャネルID、LIFF URLを用意してください。
WebhookやLIFFの公開先は、サーバーの [公開設定](../administrators/installation.md#任意のサブパス) に合わせます。

1. LINE公式アカウントのMessaging APIに、管理者が案内するWebhook URLを設定します。
   標準の公開パスでは `https://your-domain.example/bzcard-api/line/webhook` です。
2. WebUIのアカウントメニュー「LINE設定」で、利用者自身の接続情報を保存します。
3. 「LINE ID紐付けURLを発行」を押し、表示されたURLをLINEアプリで開いて紐付けます。
4. 紐付けたLINEアカウントから、公式アカウントへ名刺画像を送信して登録します。
   名刺検索やLINE内の画面での確認もできます。

公式アカウントで検索・登録できるのは、そのbzCard利用者に紐付けたLINEアカウントだけです。
LINE LoginチャネルIDを変更すると紐付けが解除されるため、新しいURLを発行して再連携してください。
シークレットとトークンは暗号化して保存し、画面から再表示しません。変更時だけ新しい値を入力します。

LINEで画像の処理が失敗した場合は再送してください。
LINEへの返信に失敗しても、登録済みの名刺は取り消されません。
